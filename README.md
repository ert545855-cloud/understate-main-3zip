# Siyaset RP

Türkçe, mobil uyumlu, çok oyunculu siyaset ve strateji oyunu. Devletini kur, meclisi yönet,
fabrikalarda tank ve silah üret, asker bas ve dünya haritasında gerçek zamanlı askeri harekât başlat.

- **Ön yüz:** React (babel-standalone, derleme adımı yok) — `index.html` + `src/`
- **Sunucu:** Node/Express + Socket.io + PostgreSQL — `server/main.js`
- **Mobil:** Capacitor (Android) — `npm run android:prepare -- https://sunucu-adresin`

Son değişiklikler için `DEGISIKLIKLER.md` dosyasına bak.
